
## Job Tracking

This is the frontend for the Job Tracking application, built using React and Vite. It leverages Redux for state management and supports routing with React Router. The project uses modern JavaScript and TypeScript features for a fast and scalable user interface.




## Tech Stack & Dependencies


- React: JavaScript library for building user interfaces
- Vite: Fast build tool for modern web development
- Redux: For state management, using Redux Toolkit
- React Router: Declarative routing for React
- Lottie React: For rendering animations with Lottie
- Tailwind CSS: Utility-first CSS framework for styling
- TypeScript: JavaScript with static typing for better maintainability
- ESLint: Linting tool to enforce code quality standards
- PostCSS & Autoprefixer: For optimizing CSS
- React Helmet: For managing document head (e.g., title, meta tags)
- use-dark-mode-ts: Custom hook for handling dark mode

## Features
- State management with Redux Toolkit
- Custom Lottie animations
- Dark mode support
- Responsive design using Tailwind CSS
- Page title management with React Helmet
- Routing with React Router
- Linting and type checking with ESLint and TypeScript
